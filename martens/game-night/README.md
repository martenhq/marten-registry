# Game Night

Add Game Night to your games group and let it keep the scores.

- **Picks the night**: a weekly question with the next few evenings, called once most of you answer.
- **Any game**: cards, board games, poker chips, a pub quiz. Tell it the result however you like.
- **Live scores**: a running total round by round, if you want one.
- **The season's table**: fair standings across big games and small ones, with past seasons kept.

It keeps score only. It never tracks real money.
