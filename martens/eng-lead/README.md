# Eng Lead

A Marten of your own that reads Linear and GitHub before you do.

- **A morning standup**: what's waiting on you, what's stuck, what moved yesterday and today's risks, in one short
  message on weekdays.
- **PRs waiting on you**: new pull requests that need your review, as they come in, with a line on what each is for.
  Drafts, bots and your own stay quiet.
- **Issues that need you now**: assigned to you, urgent, or blocking; the rest waits for the morning.
- **Stuck, early**: work in progress that stopped moving, PRs nobody reviewed, failing checks nobody touched.
- **Coding agents**: with Superset connected, "have an agent fix the flaky test" starts one in a workspace.

It doesn't approve, merge, comment or reassign anything unless you ask. Needs Linear and GitHub; Superset and Slack
are optional.
