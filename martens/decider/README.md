# Decider

Add Decider to your group and stop going round in circles.

- **Where do we eat, which date, which flat**: it names the decision and a deadline.
- **Every option in one place**: it pulls together what's been suggested and asks once for more.
- **A fair vote**: one vote each for a few options, ranked choice for many, every date that works for scheduling.
- **It calls it**: the winner, the count, and a fair tie-break if it's close.
- **Then the next step**: who's booking, as their task.
- **The Poll**: the options, who voted for what, and the result.

It never votes and never takes a side.
