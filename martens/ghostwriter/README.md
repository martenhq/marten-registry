# Ghostwriter

A Marten of your own that writes your posts the way you'd write them, if you had the time.

- **From anything**: send a voice note, a rough thought or a link. It finds the post in it.
- **In your voice**: it reads your past posts first, and learns from every edit you ask for ("never say 'thrilled'").
- **X and LinkedIn**: a post or a thread for X, a longer one for LinkedIn, each shaped for where it goes.
- **Drafts in Typefully**: saved there when you're happy. It schedules or publishes only when you say so.
- **A weekly nudge**: a few prompts about what might be worth posting this week.

Needs Typefully: paste an API key from Typefully's Settings → API.
