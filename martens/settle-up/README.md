# Settle Up

Add Settle Up to your group and stop keeping a spreadsheet of who paid for what.

- **Just say it**: "I paid 84 for dinner" is logged as it's said, split however you split it.
- **Unequal splits**: some people left out, someone in for half, exact amounts each.
- **Balances**: everyone's position in one sketch, in every currency you used.
- **Fewest payments**: it works out the shortest way to make everyone square.
- **A gentle weekly check**: open balances posted once a week, only if anything's open.

It never pays or asks for money itself. It keeps the record; you settle.
