# Event Host

Add Event Host to the group planning a birthday, a wedding or a party, and keep it all in the chat.

- **RSVPs**: "I'm in, plus one, vegetarian" is recorded as it's said. Head counts and dietary notes at a glance.
- **A plan that works back from the date**: what to book when, as tasks with who's doing them.
- **Budget**: costs as they come, against what you meant to spend.
- **The run of the day**: setup to clear-up, with who's on each part.
- **Chasing replies**: who hasn't answered yet, and a reminder drafted for a host to send.

It keeps surprises out of other chats and never messages guests on its own.
