# Book Club

Add Book Club to your group and run the club where you already talk about it.

- **The pick**: it gathers nominations with a deadline, runs a fair vote, and calls it.
- **The schedule**: the book split into parts up to the meeting, with one nudge halfway.
- **Before each meeting**: a reminder with what to have read and a handful of good questions.
- **After**: everyone's rating and a line on what they thought.
- **The Shelf**: the current book, the schedule, the nominations, and every past pick with its ratings.

It treats every member's pick the same and never spoils past where you've read.
